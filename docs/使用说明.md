# Agent 流量管家使用说明

## 安装与启动

按 [README](../README.md) 先运行 `./test.sh` 与 `./build.sh`，再安装。需要 macOS 14+、Command Line Tools、Python 3 及相应来源的登录或密钥。应用采用 ad-hoc 签名，未做 Apple 公证，按系统来源检查提示处理。

启动后在顶部菜单栏查看文字标题，没有电池图标。常规启动不弹说明窗口，再次打开应用展开菜单；“首次使用与状态”仅从菜单手动打开。首次正常启动会自动配置登录启动，可在菜单关闭。沿用 `local.codex-battery` 及上游数据目录，共享已有设置。

## 数据源与周期

Codex 使用自己已登录的本机 Codex，只读查询额度。Claude 可在官方订阅与第三方 B.AI 间切换；只有官方订阅使用 5 小时 / 每周周期。菜单中统一的周期开关同时影响 Codex 与 Claude 官方，默认 5 小时。所选周期缺失时会回落到另一个可用周期，菜单详情以 `◀ 菜单栏显示` 标出实际项，应核对该项时长。

Claude 官方案读取 Claude Code Keychain OAuth 登录，必要时回退 `~/.claude/.credentials.json`。系统可能询问钥匙串权限，过期登录需在 Claude Code 中刷新。官方接口读数不可用时不会伪造额度。

B.AI 使用积分 Credits，非美元或百分比。个人密钥显示个人余额，团队管理员显示团队余额，有限配额成员显示剩余配额；无限配额成员显示未知余额并注明无限制。缺字段是未知，真实零是 0。百万以上以 M 为主：不足 100M 两位小数，100M 至不足 1000M 一位，再大取整；不足百万显示 K 或原值。菜单详情及 `status.json` 的 `baiBalanceCredits` 为精确积分。文档中任何数字格式示例都不是当前余额。

点击“安全配置 B.AI API Key…”使用遮罩输入，支持 ⌘V 和“从剪贴板粘贴”，保存至 Keychain 服务 `local.codex-battery.bai`、账号 `api.b.ai`。剪贴板不会自动清空。也可读取进程环境或 `~/.claude/settings.local.json`、`settings.json` 的 env，但只接受同一配置中与 HTTPS `api.b.ai` 配对的 `ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_API_KEY`。余额查询固定 `GET https://api.b.ai/v1/balance`，拒绝重定向，不发送推理请求。

官方订阅与 B.AI 缓存、退避分别维护，切换提供方或更新密钥使旧请求失效。过期、失败与限流时应核对错误和更新时间，不能把缓存视为当前读数。

## DeepSeek 与今日花费估算

DeepSeek 是余额制，查询 `/user/balance`，菜单栏显示货币金额，不是百分比。API Key 依次读取 `~/.hermes/.env`、进程环境 `DEEPSEEK_API_KEY`、`~/.hermes/config.yaml` 匹配的配置。目前没有 DeepSeek 专用 Keychain 录入窗口。

今日花费由余额差分估算，以系统本地时区的当天首次成功采样建立基准，首次采样之前的消费不计入；休眠及跨天未采样也可能漏算。余额上涨按净增量平移基准，并不能证明精确充值额；同一采样间隔内充值与消费无法拆分。缩短间隔或充值后补采只能减小误差，无法补回已丢失的信息。不能承诺第二天就与官网一致。

菜单“校准今日已花费…”或可执行文件 `--set-deepseek-spent <金额>` 可手动校准。输入的官网消费必须对应同一时刻的余额；校准后仍按差分估算，不是账单对账功能。

## 刷新与公开消息

Codex 常规每 60 秒、Claude / B.AI 每 5 分钟、DeepSeek 每 10 分钟自动刷新；菜单打开、系统唤醒与会话激活也触发刷新。请求在途、退避和来源错误会影响实际执行，手动“立即刷新”为补充。公共消息单独定时查询。

公开预告、时间补充、改期和完成确认按版本提醒；打开菜单显示摘要后记为已读。可粘贴 Tibo 公开原帖链接补查。公开来源可能延迟、遗漏或不可用，不能将公告视为本人账户到账。个人保留线是自己的计划，便签仅存本机。时区显示可选北京时间或本地时间，DeepSeek 日统计仍使用本地时区。

隔离演示使用明确标记的合成数据，不查询真实账户；退出后恢复真实状态。演示或自测通过不证明真实凭据、API 或余额可用。

## 开发检查与常见问题

`./test.sh` 运行离线回归、AppKit 自测、构建和临时目标安装测试。可执行文件提供 `--check`、`--check-claude`、`--check-bai`、`--check-deepseek` 等真实只读查询；这些会访问实际来源，输出可能含个人额度或余额，不应直接公开。

找不到 Codex 时，先确认已安装并正常登录，查看 `Source/UsageClient.swift` 中候选路径。Claude 登录过期需自行刷新。接口限流时等待退避，不要反复查询。缺少周期以服务返回为准。公共消息失败不代表账户额度归零。

安装器遇到多个副本、无关应用或不同主版本时停止覆盖；同主版本更新会备份旧应用和设置。无需为额度查询开启辅助功能、屏幕录制或完全磁盘访问；详情见 [隐私说明](../PRIVACY.md)。

## 卸载与恢复

1. 从菜单关闭“登录时自动启动”，退出应用。
2. 将安装位置的“Agent 流量管家.app”移到废纸篓，默认位于 `~/Applications`，也可能沿用原安装位置。
3. 按需备份并删除本工具的 `~/Library/Preferences/local.codex-battery.plist`、`~/Library/Application Support/Codex Battery`、`~/Library/LaunchAgents/local.codex-battery.plist`。这些可能与上游共享，请先核对。
4. 同主版本升级备份位于 `~/Library/Application Support/Codex Battery Backups`。恢复前退出应用，再还原旧应用及对应设置。备份可能含个人信息，不能上传。
5. 如需删除本工具保存的 B.AI 密钥，在“钥匙串访问”中删除上述专属项；不要删除 Claude Code 或 Codex 自身的认证与聊天资料。
